# Melvo settings — Melvo Labs

This repository holds the organization's Melvo configuration. Skills live under `skills/<name>/SKILL.md` (PRD-1 FR-CFG-3); Melvo syncs them on every push to the default branch.

The static "Hello, world!" site lives under [`site/`](site/docs/README.md) — one hand-written `index.html`, a plain-markdown launch verification record, and a shell contract check. It has no `package.json`, lockfile or build configuration, by ADR-001 §4.

Questions teams ask first

Can Melvo merge code on its own?

No. Melvo opens pull requests and never merges them. Your branch protection rules and reviewers stay exactly as they are.

What happens to our source code?

Work happens in an isolated sandbox against a checkout of your repository. Nothing is used to train models and every run is logged for audit.

Which stacks does it understand?

Melvo reads your repository conventions, so it follows the stack you already use. It is in daily use on TypeScript, Python, Go and Java codebases.

How long does setup take?

About ten minutes: connect a repository, confirm the test command, and hand over a first task.
